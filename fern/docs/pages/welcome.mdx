## 빠른 시작

<Steps>
  ### Account ID 준비

  [ClawOps 대시보드](https://platform.claw-ops.com)에 가입하고 **개발자 → API & Webhooks**에서 Account ID를 확인한 뒤 API Key를 발급합니다.

  ### 에이전트 생성

  이름과 역할을 지정해 한국어 음성 에이전트를 만듭니다.

  ```bash
  curl -X POST "https://api.claw-ops.com/v1/accounts/YOUR_ACCOUNT_ID/agents" \
    -H "Authorization: Bearer YOUR_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{"name": "지원 에이전트"}'
  ```

  ### 번호 발급

  음성 통화와 SMS·LMS·MMS를 사용할 수 있는 한국 전화번호를 발급합니다.

  ```bash
  curl -X POST "https://api.claw-ops.com/v1/accounts/YOUR_ACCOUNT_ID/numbers" \
    -H "Authorization: Bearer YOUR_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{}'
  ```

  ### 에이전트 연결

  발급한 번호를 에이전트에 연결해 전화를 받을 수 있도록 설정합니다.

  ```bash
  curl -X PUT "https://api.claw-ops.com/v1/accounts/YOUR_ACCOUNT_ID/numbers/{number}" \
    -H "Authorization: Bearer YOUR_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{"routingType": "agent", "agentId": "{agentId}"}'
  ```

  ### 전화 걸어보기

  휴대폰에서 발급된 `070` 번호로 전화를 걸어보세요. 연결한 에이전트가 전화를 받고 대화를 시작합니다.
</Steps>

## 인증

모든 API 요청의 `Authorization` 헤더에 API 키를 Bearer 토큰으로 전달합니다.

```text
Authorization: Bearer YOUR_API_KEY
```
