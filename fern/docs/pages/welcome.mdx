ClawOps는 한국 전화 인프라를 위한 CPaaS API 플랫폼입니다. 070 번호를 발급하고, 음성 통화와 메시지를 처리하고, AI 음성 에이전트·VoiceML·SIP·WebRTC를 실제 전화망에 연결할 수 있습니다.

## 빠른 시작

<Steps>
  ### Account ID 준비

  [ClawOps 대시보드](https://platform.claw-ops.com)에 가입하고 **개발자 → API & Webhooks**에서 Account ID를 확인합니다. API나 SDK도 사용할 예정이라면 같은 화면에서 API Key를 함께 발급하세요.

  ```bash
  export CLAWOPS_ACCOUNT_ID="YOUR_ACCOUNT_ID"
  export CLAWOPS_API_KEY="YOUR_API_KEY"
  ```

  ### 에이전트 생성

  [대시보드 → 에이전트](https://platform.claw-ops.com/agents)에서 **새 에이전트**를 선택합니다.

  **지능형 에이전트**를 고르고 이름을 입력한 뒤 **만들고 구성하기**를 누르세요. 모델, 시스템 프롬프트와 음성을 설정하고 저장합니다.

  ### 번호 발급 후 에이전트 연결

  [대시보드 → 전화번호](https://platform.claw-ops.com/phone-numbers)에서 **번호 추가**를 눌러 070 번호를 발급합니다.

  발급된 번호의 상세 화면에서 **인바운드 라우팅 → 수정 → 에이전트**를 선택하고, 앞 단계에서 만든 에이전트를 **착신 에이전트**로 지정한 뒤 저장합니다.

  ### 전화 받아보기

  휴대폰에서 발급된 070 번호로 전화를 걸어보세요. 연결한 에이전트가 전화를 받고 설정한 프롬프트와 음성으로 대화를 시작합니다.
</Steps>

## 인증

모든 API 요청의 `Authorization` 헤더에 API 키를 Bearer 토큰으로 전달합니다.

```text
Authorization: Bearer YOUR_API_KEY
```
