ClawOps를 AI 에이전트에 연결하면 한국 전화번호를 발급하고, 전화를 걸거나 SMS·LMS·MMS를 보내며, 통화 기록·전사·요약을 자연어로 확인할 수 있습니다.

ClawOps는 MCP 호환 AI 클라이언트에서 사용할 수 있는 호스팅 MCP 서버를 제공합니다. 별도의 로컬 서버나 API Key 설정 없이 OAuth로 안전하게 연결할 수 있습니다. 이 가이드에서는 먼저 Claude Code 연결 방법을 안내합니다.

## Claude Code

### MCP 서버 추가

터미널에서 다음 명령어를 실행합니다.

```bash
claude mcp add --transport http clawops https://api.claw-ops.com/mcp
```

### ClawOps 인증

Claude Code에서 `/reload-plugins`를 실행한 뒤 `/mcp`를 입력합니다. `clawops`를 선택하고 **Authenticate**를 누르면 브라우저에서 ClawOps OAuth 인증을 진행할 수 있습니다.

<Info>
ClawOps는 호스팅 MCP와 OAuth를 사용하므로 설정 파일에 API Key를 직접 입력할 필요가 없습니다.
</Info>

### 사용해보기

인증이 끝나면 Claude Code에 자연어로 요청합니다.

```text
내 ClawOps 전화번호 목록을 보여줘.

사용할 수 있는 070 번호를 하나 발급해줘.

최근 통화 내역을 확인하고 마지막 통화 내용을 요약해줘.

01012345678로 "예약이 확인되었습니다."라는 SMS를 보내줘.
```

## AI 에이전트가 할 수 있는 일

ClawOps MCP를 연결하면 Claude Code가 다음 작업을 자연어 요청으로 수행할 수 있습니다.

| 구분 | 주요 작업 | 요청 예시 |
| --- | --- | --- |
| 전화번호 | 070 번호 발급, 목록 조회, 라우팅 설정, 반납 | *"사용할 수 있는 070 번호를 하나 발급해줘."* |
| 전화 | 발신, 종료, 통화 목록·상세·이벤트 조회 | *"내 070 번호로 01012345678에 전화를 걸어줘."* |
| 메시지 | SMS·LMS·MMS 발송과 발송 내역 조회 | *"01012345678로 예약 확인 문자를 보내줘."* |
| 통화 데이터 | 녹음 조회·삭제, 전사 생성·조회, 통화 요약 조회 | *"마지막 통화를 전사하고 핵심 내용을 요약해줘."* |
| Webhooks | 이벤트 수신 URL 등록, 목록 조회, 삭제 | *"통화 이벤트를 내 서버로 보내도록 웹훅을 등록해줘."* |
| 받아쓰기 사전 | 사전 생성, 용어 추가·수정·삭제 | *"'클로옵스'를 'ClawOps'로 표기하도록 사전에 추가해줘."* |

## 실제 활용 예시

### IDE에서 고객 문의 후속 처리

```text
최근 완료된 통화 10건의 전사와 요약을 확인해줘.
다시 연락해야 하는 고객과 요청 사항을 표로 정리해줘.
```

### 전화 연동 테스트

```text
내 070 번호와 최근 통화 상태를 확인해줘.
01012345678로 테스트 전화를 걸고, 통화가 끝나면
전사와 요약을 가져와 문제가 있었는지 알려줘.
```

### 예약 확인 문자 보내기

```text
01012345678로 "내일 오후 2시 예약이 확인되었습니다."라는
SMS를 보내고 발송 결과를 확인해줘.
```

### 서비스 용어의 전사 품질 개선

```text
받아쓰기 사전에 "클로옵스"를 추가하고 표기는 "ClawOps"로 설정해줘.
최근 통화 전사에서 해당 용어가 올바르게 표시됐는지 확인해줘.
```
