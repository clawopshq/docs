# Webhooks

ClawOps는 통화 상태, 메시지, 녹음, 전사와 요약 이벤트를 등록된 HTTPS 엔드포인트로 전송합니다.

## 권장 처리 흐름

1. 원본 요청 본문과 `X-Signature` 헤더를 읽습니다.
2. 계정의 Signing Key로 HMAC-SHA256 서명을 검증합니다.
3. 이벤트를 멱등하게 저장하거나 큐에 넣습니다.
4. 빠르게 `2xx`로 응답하고 무거운 작업은 비동기로 처리합니다.

<Warning>
  API 키와 Signing Key는 브라우저나 모바일 앱에 포함하지 마세요.
</Warning>

상세 이벤트 페이로드와 서명 검증 예제는 다음 문서 마이그레이션 단계에서 추가합니다.
