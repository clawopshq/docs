# Voice Agent

Voice Agent SDK는 애플리케이션에서 ClawOps로 지속적인 WebSocket 연결을 열고, 전화가 시작될 때 실시간 AI 세션을 연결합니다.

## 언제 사용하나요?

- 자연스러운 실시간 AI 대화가 핵심인 경우
- 로컬 개발 환경에서 인바운드 전화를 빠르게 테스트하려는 경우
- 통화 중 도구 호출, 전환, 상태 이벤트가 필요한 경우

## 기본 구조

```python
from clawops.agent import ClawOpsAgent, OpenAIRealtime

agent = ClawOpsAgent(
    from_="07012341234",
    session=OpenAIRealtime(
        system_prompt="예약 접수를 돕는 상담원입니다.",
        language="ko",
    ),
)
```

<Info>
  지원 모델, 음성, 이벤트와 도구 호출의 상세 문서는 기존 제품 문서에서 검증 후 이 저장소로 단계적으로 이전합니다.
</Info>
