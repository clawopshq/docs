# VoiceML

ClawOps가 인바운드 전화를 받으면 설정한 Webhook URL을 호출합니다. 애플리케이션은 VoiceML XML을 반환해 안내, 입력 수집, 연결, 녹음과 스트리밍 동작을 결정합니다.

```xml
<?xml version="1.0" encoding="UTF-8"?>
<Response>
  <Say language="ko">안녕하세요. ClawOps에 연결되었습니다.</Say>
</Response>
```

## 주요 동사

| 동사 | 용도 |
| --- | --- |
| `Say` | 텍스트를 음성으로 재생 |
| `Gather` | DTMF 입력 수집 |
| `Dial` | 전화번호 또는 SIP URI로 연결 |
| `Record` | 통화 음성 녹음 |
| `Connect` / `Stream` | WebSocket으로 양방향 음성 스트리밍 |
| `Redirect` | 다른 VoiceML URL로 흐름 이동 |

<Warning>
  Webhook은 공개 HTTPS 엔드포인트여야 하며, 운영 환경에서는 반드시 요청 서명을 검증하세요.
</Warning>
