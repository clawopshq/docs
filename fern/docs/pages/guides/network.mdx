# Network

ClawOps 연동은 HTTPS, WSS, SIP와 RTP 경로를 사용할 수 있습니다. 방화벽을 적용하는 고객은 사용하는 기능에 맞는 포트와 ClawOps 고정 IP를 허용해야 합니다.

<Info>
  운영 IP와 포트는 변경 관리가 필요한 정보입니다. 현재 제품 저장소의 검증된 네트워크 문서를 기준으로 이전한 뒤, 변경 시 두 저장소가 어긋나지 않도록 자동 검사를 추가할 예정입니다.
</Info>

공개 전에는 플랫폼 운영팀이 최신 네트워크 값을 검토해야 합니다.
