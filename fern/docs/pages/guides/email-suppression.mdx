메일을 계속 보내려면 **받고 싶어 하지 않는 사람에게 보내지 않는 것**이 가장 중요합니다. 반송률과 스팸 신고율이 높아지면 메일이 스팸함으로 가기 시작하고, 심하면 발송이 정지됩니다.

수신거부 목록에 오르는 길은 둘입니다.

| | 언제 |
| --- | --- |
| **고객이 등록** | 수신거부 요청을 받았을 때 콘솔이나 API 로 넣습니다 |
| **자동 등록** | **영구 반송**과 **스팸 신고**가 생기면 ClawOps 가 자동으로 올립니다 |

어느 쪽이든 같은 목록에 들어가고, 콘솔에서 등록 사유와 함께 보입니다. 등록된 주소는 다음 발송부터 **자동으로 제외되고 과금되지 않습니다.**

<Note>
  **일시적 반송은 자동 등록하지 않습니다.** 상대 메일함이 가득 찼거나 서버가 잠시 응답하지 않은 경우(`Transient`)는 나중에 정상 수신될 주소입니다. 영구 반송(`Permanent`, 없는 주소 등)과 스팸 신고만 올립니다.
</Note>

## 수신거부 목록

[콘솔의 수신거부](https://platform.claw-ops.com/blocked-recipients)에서 채널별로 관리합니다. 전화·문자·이메일이 **각각 별개 항목**이라, 같은 상대를 전화와 문자 모두 막으려면 두 건으로 등록합니다.

![수신거부 화면](/assets/email/suppression.jpg)

등록된 주소는 발송 시 **자동으로 제외됩니다.** 요청이 실패하는 게 아니라 그 사람만 빠지고 나머지에게는 나갑니다.

- 50명 중 2명이 수신거부 상태였다면 **48명에게 발송되고 48건으로 과금**됩니다.
- 제외된 주소는 발송 응답과 이력에 남아 확인할 수 있습니다.
- **전원이 수신거부 상태일 때만** 요청이 `422 recipient_blocked` 로 거절됩니다.

### API 로 등록하기

```bash title="cURL"
curl -X POST "https://api.claw-ops.com/v1/accounts/YOUR_ACCOUNT_ID/blocked-recipients" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "recipient": "customer@example.com",
    "channel": "email"
  }'
```

`channel` 은 `call`·`message`·`email` 중 하나입니다. `recipient` 에는 채널에 맞는 값을 넣습니다 — 전화·문자면 전화번호, 이메일이면 이메일 주소입니다.

<Note>
  이메일 주소는 대소문자를 가리지 않고 찾습니다. 대문자가 섞인 주소로 등록해도 소문자로 온 메일이 함께 걸립니다.
</Note>

### 해제

해제해도 **이력은 남습니다.** 언제 등록되고 언제 풀렸는지 확인할 수 있습니다.

## 반송과 스팸 신고

발송 API 의 `201` 은 접수됐다는 뜻일 뿐입니다. 실제 결과는 나중에 webhook 으로 옵니다.

| 이벤트 | 뜻 | 자동 등록 |
| --- | --- | --- |
| `email.delivered` | 상대 메일 서버가 받았습니다 | — |
| `email.bounced` (`Permanent`) | 없는 주소 등으로 영구 반송됐습니다 | ✅ 자동으로 수신거부에 오릅니다 |
| `email.bounced` (`Transient`) | 메일함이 가득 찬 등 일시적 반송입니다 | ❌ 나중에 정상 수신될 수 있어 올리지 않습니다 |
| `email.complained` | 받는 사람이 스팸으로 신고했습니다 | ✅ 자동으로 수신거부에 오릅니다 |
| `email.failed` | 발송에 실패했습니다 | — |

webhook 의 `BounceType` 으로 영구·일시를 구분할 수 있습니다. **영구 반송과 스팸 신고는 따로 등록하지 않아도 됩니다** — 다음 발송부터 자동으로 빠집니다.

<Tip>
  일시적 반송이 같은 주소에서 반복된다면 그 주소는 실제로 죽었을 가능성이 높습니다. 그때는 직접 등록하거나 명단에서 지우세요.
</Tip>

<Warning>
  **반송률과 스팸 신고율은 계정의 발송 자격을 결정합니다.** 공급자 기준을 넘으면 발송이 정지되고, 그때는 API 가 `403 email_sending_paused` 를 돌려줍니다. 정지되면 고객센터로 문의해 주세요.
</Warning>

반송을 줄이는 가장 확실한 방법은 **동의받은 주소에만 보내는 것**입니다. 구매한 명단이나 오래된 명단은 반송률이 높아 계정 전체를 위험하게 만듭니다.

## 이메일 기록

[콘솔의 이메일 기록](https://platform.claw-ops.com/email-logs)에서 보낸 메일과 받은 메일을 함께 볼 수 있습니다.

![이메일 기록 화면](/assets/email/email-logs.jpg)

방향(발신·수신), 상대 주소, 제목, 첨부 개수, 상태, 시각이 표시됩니다.

<Note>
  **반송된 메일은 이 목록에서 `발송됨` 으로 남습니다.** 접수 시점에 기록되기 때문입니다. 반송 여부는 webhook 으로 확인하세요.
</Note>

## 광고성 메일을 보낼 때

영리 목적의 광고성 정보를 이메일로 보낸다면 **정보통신망법 제50조**를 따라야 합니다. 이 의무는 발송하는 고객에게 있습니다.

- 수신자의 **사전 동의**를 받아야 합니다.
- 제목 맨 앞에 **`(광고)`** 를 표시해야 합니다.
- 본문에 **수신거부 방법**을 명시하고, 그 수단은 **무료**여야 합니다.
- 수신거부 의사를 밝히면 **지체 없이 발송을 중단**해야 합니다.

<Warning>
  ClawOps 는 제목에 `(광고)` 를 자동으로 붙이지 않고, 수신거부 링크도 자동으로 넣지 않습니다. **본문과 제목은 보내는 쪽이 책임집니다.**
</Warning>

<Note>
  이 문서는 법률 자문이 아닙니다. 실제 적용은 상황에 따라 다르므로 필요하면 전문가의 확인을 받으세요.
</Note>

수신거부 요청을 받으면 [수신거부 목록](#수신거부-목록)에 등록해 두면 이후 발송에서 자동으로 제외됩니다. 반송·스팸 신고로 자동 등록된 것과 같은 목록입니다.
